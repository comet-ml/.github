# Security Policy

This is the default security policy for repositories in the [comet-ml](https://github.com/comet-ml) organization. A repository that ships its own `SECURITY.md` overrides this one.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, pull requests, or Slack.**

Report privately through GitHub, on the repository where you found the issue:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability** to open a private security advisory.
3. Include as much of the following as you can:
   - The type of issue, and the affected component or endpoint.
   - Affected version, commit, or deployment.
   - Step-by-step reproduction, including any proof-of-concept.
   - The impact you believe an attacker could achieve.

If the Security tab does not offer private reporting on that repository, open the advisory on [comet-ml/opik](https://github.com/comet-ml/opik/security/advisories/new) instead and say which repository the report concerns.

## What to expect

- We aim to acknowledge a report within **3 business days**.
- We will keep you updated as we investigate, and let you know when a fix ships.
- We will credit you in the advisory when a fix is published, unless you ask us not to.

## Scope

This policy covers the source code in comet-ml's public repositories. Reports about the hosted Comet platform are welcome through the same private channel and will be routed to the platform team.

Please give us a reasonable window to ship a fix before disclosing publicly.
